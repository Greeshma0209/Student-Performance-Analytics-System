# Project Documentation: Student Performance Analytics System

## 1. Introduction
The Student Performance Analytics System is developed using Python to analyze students' academic performance and attendance.

## 2. Objective
The main objective is to calculate student marks, assign grades, identify pass/fail results, and analyze academic performance.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Google Colab

## 4. Dataset Description
The dataset contains 20 student records with the following fields:
- Student ID
- Name
- Department
- Python marks
- AI marks
- Maths marks
- Attendance percentage

## 5. Implementation
Pandas is used to organize and analyze student data. NumPy is included for numerical computing. Python functions and conditional statements are used to assign grades and determine pass/fail results.

## 6. Features Implemented
1. Calculate total marks and average marks.
2. Assign grades based on average marks.
3. Identify pass and fail students.
4. Analyze attendance status.
5. Calculate overall class performance.
6. Compare department-wise performance.
7. Calculate subject-wise average marks.
8. Display the top five performing students.

## 7. Results
- Total students: 20
- Class average marks: 71.73
- Highest average marks: 92.33
- Lowest average marks: 35.33
- Students passed: 18
- Students failed: 2
- Average attendance: 83.25%

## 8. Conclusion
The project demonstrates how Python and data analysis libraries can be used to summarize student performance and identify useful academic insights.
