# Student Performance Analytics System

## Project Description
The Student Performance Analytics System is a Python-based project that analyzes student academic performance using Pandas and NumPy.

It calculates total marks, average marks, grades, pass/fail results, attendance status, department-wise performance, subject-wise averages, and top-performing students.

## Technologies Used
- Python
- Pandas
- NumPy
- Google Colab

## Dataset
The dataset contains information about 20 students, including:
- Student ID
- Name
- Department
- Python, AI, and Maths marks
- Attendance percentage

## Key Features
- Calculate total and average marks
- Assign grades to students
- Identify pass and fail results
- Analyze student attendance
- Calculate overall class performance
- Compare department-wise performance
- Calculate subject-wise average marks
- Identify the top 5 performing students

## Project Files
- `Student_Performance_Analytics.ipynb` — Python code and analysis
- `Student_Performance_Analytics.csv` — Student dataset

## Conclusion
This project demonstrates how Python, Pandas, and NumPy can be used to analyze student performance and generate useful academic insights.
